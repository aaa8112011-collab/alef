# حالة التحقق

## ما أُنجز

- واجهة عربية RTL في إضافة Chrome Manifest V3، مع اختيار مادة، إعدادات الربط، عرض السؤال والشرح، سجل جلسة، وزر إيقاف.
- قارئ يدعم النص العربي والإنجليزي، القطع القرائية والحركات، الاختيار الواحد والمتعدد بعناصر ألف المخصصة، حقل نص واحد، قائمة منسدلة واحدة، المطابقة النصية وفراغات الكلمات ذات التفاعل المعروف.
- حل افتراضي مجاني عبر Ollama على الجهاز، دون مفتاح خدمة. النموذج الافتراضي `qwen3:8b` مناسب من حيث الذاكرة لجهاز المستخدم ذي 32GB، ولا يضمن ذلك سرعة أو دقة معينة. يبقى المزوّد الخارجي عبر HTTPS خيارًا مستقلًا.
- التحقق الثاني مستقل عن الجواب الأول ويقارن النتيجة؛ حد الثقة الأدنى 0.85.
- خادم محلي مرتبط بـ `127.0.0.1` ورمز اقتران خاص؛ لا تُمرّر مفاتيح المزوّد إلى الصفحة أو الإضافة.
- يُسجّل الدرس للمراجعة عند اختلاف التحقق أو عدم دعم السؤال، ثم تُتابع الدروس التالية متى أمكن الرجوع إلى القائمة. الإرسال اليدوي أو فقدان الاتصال الأساسي أو تبدّل نطاق الموقع يوقف التشغيل.
- ملف تشغيل ويندوز يفحص البرامج والنموذج قبل بدء الخدمة، ويحمّل النموذج عند غيابه، وينسخ رمز الربط محليًا. لا يعدّل `.env` ولا يحتاج مفتاح API.

## الحدود التي تمنع ادعاء التشغيل الكامل على ألف

تم استرجاع الصفحة العامة `moe.alefed.com` وملفات الواجهة أثناء تطوير الإصدار 0.3 بحالة HTTP200. قُرئت المكوّنات الفعلية للمواد والمستويات والتدريب وعناصر الأسئلة، وبُنيت الاختبارات وفق بنيتها. تفاصيل العناصر في [ALEF-ADAPTER.md](ALEF-ADAPTER.md). لم تتوفر جلسة طالب، ولم تُجرَ عمليات إرسال في حساب ألف.

Ollama غير مثبت في هذه البيئة، والوصول إلى `ollama.com` و`docs.ollama.com` محجوب من بوابة الشبكة. قُرئ توثيق API الرسمي من مستودع Ollama على GitHub، وتحققت الاختبارات من بروتوكوله عبر خادم HTTP محلي. لم تُنزّل أوزان نموذج ولم يُختبر استدلال نموذج حقيقي أو دقته. لا يُطلب مفتاح مدفوع لعلاج غياب Ollama.

بيئة التنفيذ Linux، لذلك لم يُنفّذ ملف CMD أو مثبت Ollama على ويندوز فعلي. اختبارات المشغّل تحاكي عمليات النظام صراحةً وتتحقق من التنزيل والجاهزية والفشل وحماية الإعدادات. تبقى تجربة ويندوز الحقيقية على جهاز المستخدم خطوة لازمة.

تمنع سياسة Chromium المُدار في بيئة التطوير تثبيت أي إضافة (`ExtensionInstallBlocklist: ["*"]`)، لذلك تعذر اختبار تحميل Manifest V3 نفسه في متصفح البيئة. لم تُعدَّل السياسة. تستخدم اختبارات المحتوى والعامل الخلفي واجهات Chrome محاكية صراحةً مع DOM متصفح حقيقي؛ وهي لا تثبت نجاح تثبيت الإضافة على جهاز المستخدم.

تُختبر دورة الحل بصفحة HTML محلية ومزوّد اختبارات محدّد. لم تُقَس دقة الإجابات على واجبات حقيقية أو سرعة مزوّد حقيقي. تعني إحصائية «إجابات أُرسلت» أن الإضافة ضغطت زر الإرسال، ولا تثبت قبول الموقع أو صحة الحل.

يلزم للتشغيل المحلي الفعلي تثبيت Ollama والنموذج، وتثبيت الإضافة على الكمبيوتر، وفحص عناصر واجهة ألف بعد الدخول. لا يلزم أي مفتاح API في الوضع الافتراضي. يدعم الإصدار 0.3 قوائم الدروس والمستويات المفتوحة المعروضة والتنقل بين شرحها وتدريبها والعودة إلى القائمة. التدريب المشترك للمستوى يُجرى مرة واحدة عبر أحد أنشطته. اختُبر ذلك محليًا، ويظل التوافق داخل الحساب الحقيقي غير متحقق منه. الصور والأسئلة ذات عدة قوائم أو محرر المعادلات الخاص وبعض التفاعلات الأخرى قد تحتاج تطويرًا إضافيًا. الدروس المقفلة ومتطلبات الفيديو غير القابلة للتخطي لا تُغيّر.

## اختبارات قابلة للتكرار

تشمل الاختبارات الخادم والحل، وتدفق DOM والعامل الخلفي، والواجهة العربية، وترتيب عمليات تشغيل ويندوز. تتضمن اختبارات Ollama طلبات HTTP فعلية لخادم اختبار محلي مع تحقق أن الطلبات لا تستخدم مفتاحًا أو ترويسة Authorization. يُفحص الأرشيف للتأكد من سلامته واستبعاد ملفات الأسرار.

نتيجة الإصدار 0.3: **103 اختبارات ناجحة، بلا فشل أو تخطٍّ**: 43 للخادم والحل، و30 لقارئ الأسئلة والتفاعلات، و13 لرحلة المواد والدروس، و4 للواجهة، و13 لتشغيل ويندوز المحاكى. تشمل حالات عربية ذات حركات وقطع مطوية، وعناصر ألف المخصصة، والقوائم والمطابقة والسحب، ومسار مستويات يزور كل تدريب مرة واحدة، وتصحيح إجابة مرفوضة بمحاولة محدودة، والإيقاف أثناء المطابقة.

نتيجة الإصدار 0.2: **74 اختبارًا ناجحًا، بلا فشل أو تخطٍّ**: 40 للخادم والحل، و18 لتدفق المتصفح، و3 للواجهة، و13 لتشغيل ويندوز المحاكى. نجح أيضًا تشغيل الخادم الحقيقي محليًا، وإظهار غياب Ollama بدقة في الحالة وطلب الحل، دون طلب مفتاح مدفوع.

- `npm run check`: صلاحية ملف Manifest وصياغة ملفات JavaScript.
- `npm test`: اختبارات API والتحقق، واختبارات Chromium للقراءة والإرسال والإيقاف على الموقع التجريبي.
- `npm run test:browser`: اختبارات تدفق DOM والعامل الخلفي فقط.
- `npm start`: يُشغّل الخادم الحقيقي. `GET /api/health` يفحص وصول Ollama ووجود النموذج؛ يُظهر `configured:false` وسببًا واضحًا عند غياب أحدهما. `/api/solve` يعرض فشلًا صريحًا بدل إرجاع نتائج وهمية.

وجود اسم النموذج في قائمة Ollama لا يثبت نجاح الاستدلال؛ يلزم حل سؤال فعلي. لا يُعد نجاح اختبارات البروتوكول والمحاكاة دليلًا على جودة إجابات النموذج أو توافق واجهة ألف. لا توجد نتائج نجاح مفترضة.

تُظهر الصور `dashboard.png` و`dashboard-fixture.png` و`dashboard-course.png` الواجهة ببيانات تجريبية محلية عبر محاكي Chrome API واضح، وتحمل علامة بذلك. لا تعرض حساب ألف حقيقيًا.

## مسودة بيئة السحابة

حُفظت تعليمات بدء التشغيل الجديدة ومتغيرات الوضع المحلي كمسودة، ولم تُنشر. تفعيل المسودة يتطلب مراجعتها وحفظها ثم نشر البيئة. لا يحتاج تشغيل مشروع ويندوز إلى نشر بيئة السحابة. متطلب `SOLVER_API_KEY` القديم في مسودة السحابة أصبح غير مستخدم في الوضع المجاني؛ أداة التحديث تدعم إضافة المتطلبات ولا تدعم حذفها، ويمكن حذفه من واجهة مراجعة إعداد البيئة إذا استُخدمت. لا يلزم توفير مفتاح بدل حذفه.
