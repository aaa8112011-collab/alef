# ربط ألف في الإصدار 0.5.6

قُرئت الصفحة العامة `https://moe.alefed.com/` وملفات JavaScript التابعة لها بنجاح أثناء العمل الحالي. لم يُستخدم حساب طالب أو اتصال API خاص ولم تُستخرج جلسات دخول. العناصر التالية ملاحظة في الشفرة العامة المنشورة، وليست ادعاءً بتجربة حساب حقيقي:

- بطاقات المواد: `[data-testid="subject-card"]`، العنوان `[data-testid="subject-title"]`، ومعرّف `pathway-subject-cards-*`. تنتقل إلى `/pathways/classes/{classId}`.
- مستويات For You المعروضة: `[data-testid="levels-container"]` و`[data-testid^="level-card-container-"]` والعنوان `[data-testid="level-title"]`. لا ينتقل القارئ تلقائيًا إلى قسم NEXT LEVELS لفتح محتوى مستقبلي.
- أنشطة المستوى: `ul[aria-label="SkillList"]` وعناصر `li[aria-label="Skill"]` داخل غلاف يستقبل النقر.
- الشرح: `[data-testid="content-page"]` و`[data-testid="content-page-body-player"]`. الاختصار `#skill-player-practice` ينتقل إلى التدريب **المشترك للمستوى**؛ لذلك يدخل البرنامج نشاطًا واحدًا للوصول إليه، ثم ينتقل للمستوى التالي بعد اكتماله ولا يعيده لكل مهارة.
- الأسئلة: `[data-testid="question-renderer"]` مع رمز السؤال الفرعي. بطاقات `[data-testid="choice-item"]` تستقبل النقر. حقول radio/checkbox الأصلية مخفية؛ قراءة الاختيار المؤكد تعتمد على حالة `.choice.selected`.
- النص القرائي: `[data-testid="question-passage-content"]`، وتُفتح القطعة المطوية عند توفر زرها قبل طلب الحل. تُحفظ الحركات العربية.
- القوائم: select الأصلي، وcombobox/React Select الذي يعرض عناصر role=option عند فتحه. يدعم الإصدار قائمة واحدة في السؤال.
- المطابقة النصية: `matching-choice-*` و`matching-answer-*`؛ المكتبة توفر اختيار الزوج بالنقر أيضًا. الفراغات `fill-blank-dd-*` والكلمات `draggableChoice` توفر اختيار الكلمة ثم موضعها؛ يتطلب التطبيق إقرار الواجهة بالموضع قبل الإرسال.
- اكتمال تدريب Pathways عند نافذة Proficient ذات `[data-testid="go-super-pro-btn"]`. زر Continue Practice في ارتقاء المرحلة الوسيطة يعني المتابعة، ولا يُحسب وحده اكتمالًا.

مصادر الملاحظة: ملف الوحدة العامة `/student_pathways/__federation_expose_Module.4364567e258a482e.js` ومكوّن مكتبة الأسئلة `/student_pathways/4295.c5a798bbfabfa8af.js` والملفات العامة التابعة لهما. لم تُنسخ الحزم إلى المستودع؛ يحوي المشروع قارئًا مستقلًا واختبارات HTML مشتقة من بنية العناصر الملاحظة.

## واجهة المهام المسندة Core Coursework ومشغّل NCLE

أظهرت لقطة المستخدم صفحة المادة ذات تبويبات «صفحتي / المهام المسندة / جميع الدروس»، ومسارها من الشكل `/#/classes/{classId}?tab=forYou`. قُرئت ملفات الواجهة العامة وخرائط المصدر للمقاطع `2360` و`6654` و`492` و`3424` و`1654`. تؤكد مكوّنات `AssignedItemCard` و`AssignedTasksPanel` و`AssignedTab` و`AllLessonsTab` البنية التالية:

- تبويبا المهام وجميع الدروس: `core-coursework-assigned-tab-select` و`core-coursework-alllessons-tab-select`، وكل المحددات هنا تستخدم الخاصية `data-testid`.
- بطاقات «صفحتي» والمهام: `core-coursework-foryou-activity-card-navigate` و`core-coursework-assigned-activity-card-navigate`. العنوان داخل `h3[dir=ltr]`، والنقر يكون مرة واحدة على البطاقة أو زرها الداخلي `*-activity-btn-navigate`.
- «إظهار المزيد»: `core-coursework-foryou-showmore-btn-expand` و`core-coursework-assigned-showmore-btn-expand`.
- مرشحات المهام: `core-coursework-assigned-all-chip-filter` و`*-todo-chip-filter` و`*-overdue-chip-filter` و`*-completed-chip-filter`. مرشح To Do لا يشمل المتأخر؛ لذلك يستخدم المشغّل All ثم يستبعد المكتمل والمقفل من صفوف الدروس.
- بطاقات جميع الدروس: `core-coursework-alllessons-activity-card-navigate`، وعنوانها `div.body-lg-regular.line-clamp-2[dir=ltr]`. علامة `lock-icon` تعني قفلًا، و`in-review-label` تعني انتظار المراجعة. لا تُفتح هذه العناصر بالقوة.
- لا توفّر بطاقات المهام معرّف درس ثابتًا في DOM؛ يشتق القارئ هوية من العنوان والوجهة المرئية، ويزيل تكرار البطاقات المتجاوبة.

مشغّل الدروس من الشكل `/#/progress/ncle/class/{classId}/lesson/{lessonId}/material/...`:

- الصفحة `ncle-activity-page`؛ المحتويات `ncle-main-contents` وأزرارها `ncle-component-item`. العنصر الحالي يحمل `aria-current=step` والمكتمل علامة `ncle-component-item-completed`.
- التالي والإنهاء: `activity-navigation-bar__next-button` و`activity-navigation-bar__finish-button`. قد يكون نص التالي «Go to …»؛ لذلك لا يكفي البحث عن النص Next وحده. يدعم القارئ أيضًا `#alef-next-button` و`data-testid=next-button`.
- تأكيد تخطي الشرح: `skip-content-modal-leave-button`، وقد يكون العنصر div.
- العودة: `ncle-sidebar-back` و`ncle-completion-page-back`.
- `ncle-assessment-result` نتيجة قسم فقط. `ncle-completion-page` اكتمال الدرس كله.
- قد يكون زر المكوّن غير المعيّن غير معطّل برمجيًا، مع مظهر `text-primary-60` يؤدي إلى `ncle-lock-screen`. لا يستخدم المشغّل أزرار `ncle-component-item` اختصارًا للأسئلة؛ يتبع خطوات المحتوى بالترتيب، ولا يفتح المقفل.

يُقرأ مسار hash مع pathname لتحديد سياق الدرس وتغيّر الصفحة. لا تُحفظ معرّفات حساب المستخدم أو روابطه الخاصة في الشفرة أو بيانات الاختبار.

## تفعيل التبويبات في 0.4.1

أظهر تقرير المستخدم أن 0.4 يتعرّف على الصفحة لكنه يتوقف عند فتح تبويب المهام المسندة. في الحزمة العامة `7846.aca43159d49214d6.js`، الوحدة `10091`، يستخدم `TabsTrigger` من Radix حدث `onMouseDown` لزر الماوس الأساسي مع `ctrlKey=false` لاستدعاء تغيير التبويب، ولا يفعّله `onClick` وحده. لذلك لم يكن `HTMLElement.click()` كافيًا.

يرسل القارئ الآن تسلسل `mousedown → mouseup → click` إلى عناصر `role=tab` فقط، ويتحقق من اتصال العنصر وإتاحته بين الأحداث لأن React قد يستبدله عند الانتقال. تبقى أزرار الإجابة والإرسال والدروس على نقرة واحدة. يحاكي الاختبار الجديد عقد الأحداث المستخرج من المصدر؛ فشل قبل الإصلاح وبقي المسار `forYou`، ثم نجح بعده. لا يدّعي الاختبار تشغيل مكوّن Radix الأصلي أو حساب طالب حقيقي.

## التقدم داخل الدرس في 0.4.2

كشف تقرير المستخدم عن فتح دروس كثيرة مع صفر إرسال. كانت قائمة العامل الخلفي لا تحتفظ بخاصية `kind` للدرس، فيُقبل تغيّر تخطيط كتالوج Core Coursework قبل ظهور المشغّل ويُعامل كأنه قائمة أنشطة داخل المستوى. تُحفظ الخاصية الآن، وينتظر فتح المشغّل قبل معالجة السؤال. يتوقف التشغيل في الدرس الحالي عند تعذّر التطبيق أو غياب الإرسال أو انخفاض الثقة؛ تظل الدروس التالية بانتظار الحل. لا تُعرض المراجعات كتقدم مكتمل.

يتبع المشغّل خطوات محتوى NCLE بالترتيب، ولا يستخدم عناصر `ncle-component-item` للقفز إلى التقييم. تُستخدم أزرار Start وNext وI’ll try later المتاحة، ثم تُحل الأسئلة المدعومة وتُرسل تلقائيًا عند تفعيل الإرسال. لا يُحسب `ncle-assessment-result` اكتمالًا لكل الدرس.

تستخدم أسئلة Weaver الجديدة `.mcq-container.question-widget` وحاوية `question-statement-container` بجانب مجموعة الخيارات. قراءة `radiogroup` وحدها تفقد نص المسألة وتُبقي عبارة التعليمات العامة. وتضيف الواجهة كلمة Selected إلى الوصف الصوتي للخيار بعد اختياره؛ يجب اشتقاق معرّف الخيار ونصه من المحتوى الثابت، وقراءة `aria-checked` لإقرار الاختيار، دون إدخال وصف الحالة المتغيّر في بصمة السؤال. يُنتظر إقرار الاختيار وإتاحة زر الإرسال دون إعادة ضغط الإرسال.

قُرئت هذه البنية من المصادر العامة `weaver-player-mfe/3834.c21fd9a92463b040.js.map` للاختيار، و`4765.c7c2900bb39fb2ec.js.map` لأزرار الانتقال، و`6758.ee8dd72912395f92.js.map` للقوائم، و`2943.a7f5d28e78b16371.js.map` للسحب، و`3698.ca979170463b4362.js.map` و`6810.1827b7b0438b19d2.js.map` للكتابة. لم تُضمَّن هذه الحزم في المشروع.

يدعم القارئ قائمة Weaver واحدة داخل `.dropdown-container.question-widget` مع خيارات `role=option` التي قد تظهر في body، ويحافظ على بصمة ثابتة للفراغ قبل الاختيار وبعده. يدعم textarea في `.open-ended-container.question-widget` وحقلًا أصليًا واحدًا في `.fib-container.question-widget`. محرر `math-field` وعدة قوائم أو عدة حقول تحتاج ربطًا آخر وتتوقف للمراجعة.

في السحب النصي داخل `.dnd-container.question-widget`، يربط القارئ `.dnd-options-draggable` بالفراغ `.dnd-droppable[data-index]`. يستخدم المصدر العام DndKit MouseSensor بمهلة تفعيل 100ms، بينما أفاد المستخدم بأن نسخته تحتاج قرابة ثانية. ينتظر 0.5.6 إقرار بدء السحب الفعلي مع استمرار ضغط الزر ضمن مهلة محدودة، ثم يعيد حساب موضع الفراغ ويتحقق من الإسقاط والكلمة كاملة قبل الإرسال. لا تعمل أحداث HTML DragEvent وحدها مع هذا النوع. تبقى الصور وترتيبات السحب الخاصة والكلمات المتكررة غير المميَّزة خارج هذا الربط. يميز عدّاد `progress-bar-slide-count` الشرائح المتجاورة المتشابهة.

تعرض مساحة الإجابة المادة والدرس وحالة الاقتراح أو الإرسال. يُزال الجواب السابق عند فتح سؤال أو درس جديد؛ يحمل سجل الأحداث سياق الدرس كي لا تختلط الإجابات.

## النص والرسم معًا في 0.5.0

يرتبط الرسم ببصمة السؤال من خلال بيانات مرئية ثابتة، وتشمل صور IMG وcanvas وSVG وخلفيات CSS داخل السؤال أو سياقه التعليمي القريب الذي يضم سؤالًا واحدًا. لا تُضاف صور الشريط الجانبي أو أسئلة الشرائح السابقة. الأيقونات الصغيرة ومخرجات المعادلات النصية لا تُعد رسمًا بديلًا عن المسألة؛ الصورة التعليمية الكبيرة تبقى مطلوبة حتى إذا وُسمت presentation.

تعيد قراءة السؤال `requiresVision` وبيانات وصفية دون روابط الصور أو بكسلاتها. تطلب رسالة `ALEF_GET_VISUALS` الصور الأصلية بعد التحقق من المعرّف والبصمة، وتتحقق من ثبات السؤال بعد كل التقاط. تُلتقط حتى ثلاث صور PNG/JPEG بحد 1MB للصورة، مع حفظ ترتيبها ومعرّفات خياراتها. عند منع CORS تعاد محاولة تحميل الصورة دون بيانات اعتماد إذا سمح المصدر بذلك؛ لا تُلتقط أدلة جزئية عند الفشل. يُرفض SVG الذي يعتمد على محتوى خارجي أو foreignObject حتى لا تُحذف منه معلومات لازمة.

يفحص العامل الخلفي `protocolVersion:2` حتى لا تمرر الإضافة الجديدة الصور إلى خادم قديم يتجاهلها. تُرسل البكسلات في طلب الحل فقط، مع النص العربي أو الإنجليزي وأوصاف الصور وترتيبها؛ تبقى خارج سجل الأحداث. يفحص الخادم `/api/show` في Ollama لوجود قدرة `vision` ويوجه الصور إلى `qwen3-vl:8b`، ولا يعود تلقائيًا إلى النموذج النصي عند تعذر الرسم. يُوقف السؤال الذي يشير إلى رسم مفقود حتى إن كانت خياراته نصية.

وضع الدقة الأعلى يفعّل التفكير للنموذج النصي والمراجعة المستقلة، أو يستخدم حسابًا دقيقًا لبعض العمليات الصريحة المدعومة. لا يُعد ذلك ضمانًا لصحة إجابات النموذج؛ بيانات الصور الغامضة واتفاق استدلالين على خطأ يبقيان حدًا عمليًا.

## إطارات الدروس في 0.5.1

كشف سجل المستخدم توقف درس «الاستعارة» عند وجود إطار لم يستطع القارئ الوصول إلى مستنده. لا يثبت السجل وحده عنوان الإطار. تؤكد الصفحة العامة `https://moe.alefed.com/AppConfig.js` أن نطاق المحتوى المهيأ هو `content.alefed.com`. وتعرض خريطة المصدر `2360.b830ef86f0534729.js.map` مكوّن `ContentPlayer.js` بإطار STATIC ذي `data-testid=iframed-mlo`، ووجهته مشتقة من مادة الدرس؛ وتستخدم التكليفات `ncle-extra-content-assignment-player`. إطار `lesson-float-iframe` مساعد ولا يُعامل تلقائيًا كسؤال لازم.

يقرأ العامل قائمة إطارات التبويب المرتبط فقط عبر `webNavigation.getAllFrames`، ويطلب إذن Chrome للنطاق المرصود من ألف، ثم يحقن القارئ ويستهدف الرسائل بـ `frameId`. تبقى صفحة المادة العليا هي مرجع النطاق والمادة، ويُطابق السؤال وبصمته داخل إطار المحتوى. لا يكفي إذن الصفحة العليا لقراءة إطار من نطاق آخر، ولا يُعطّل البرنامج سياسات الأصل أو CORS.

لا يُحسب إكمال نشاط داخل الإطار اكتمالًا لكل درس NCLE؛ يستأنف المشغّل أزرار الصفحة العليا الطبيعية عند تأكيد انتهاء النشاط، أو عندما يفعّل الموقع زر «التالي» لمحتوى شرح محمّل لا يعرض أدوات تنقّل داخله. تبقى الأسئلة الظاهرة والإطارات غير المقروءة أو التي ما زالت تُحمّل مانعة لهذا الانتقال. عند غياب الإذن يتوقف على الدرس الحالي وتبقى القائمة محفوظة، ويستأنف من مكانه بعد زر السماح. تُستبعد الإطارات المساعدة وغير المرئية، ويُوقف الالتباس بين عدة أسئلة بدل اختيار إطار عشوائي.

يعرض `AssessmentContentPlayer` التقييم في `[data-testid=assessment-content-player]` عبر تطبيق منفصل اسمه `alef-assessment-player`؛ ليس كل سؤال داخل إطار STATIC. يتطلب ملف `alef-assessment-player/manifest.json` جلسة دخول ويُرجع `Unauthorized` في الطلب العام. لم يتوفر عنوان حزمة درس STATIC أو عناصر أسئلتها الفعلية، لذلك لا يُعد دعم الإطار دليلًا على دعم جميع أنواع أسئلة الدروس العربية.

قد تظهر قشرة مشغّل NCLE قبل تحميل أدواته. لذلك يُميَّز التحميل المرصود عن السؤال غير المدعوم أو الإذن المفقود، مع انتظار محدود قابل للإيقاف. وتعرض الواجهة حالة البدء والعمل والتوقف من العامل الخلفي دون تحويل حدث توقف مبكر إلى حالة عمل وهمية.

## السؤال الظاهر وتعذّر الاتصال في 0.5.2

أبلغ المستخدم عن سؤال وخيارات ظاهرة في «45. Dilations - Exit Ticket»، مع رسالة تفترض مشاهدة أو تفاعلًا يدويًا. أمكن إنتاج المسار نفسه محليًا في حالتين: خيارات radio مسماة داخل نطاق `assessment-content-player` المرصود من المصدر العام دون fieldset أو radiogroup، وحاوية سؤال معروفة ذات `display:contents` يظهر أبناؤها دون مستطيل للحاوية. لا تثبت هاتان الحالتان بنية السؤال داخل حساب المستخدم؛ لم يتوفر مستند الدرس المصادق عليه.

يدعم القارئ مجموعة radio واحدة واضحة داخل مشغّل ألف المعروف، مع تسميات مقروءة وزر تقييم معروف؛ تظل عناصر Weaver والعقود الصريحة هي الأولوية. تُرفض مجموعات الاختيار المتعددة أو الناقصة، ولا يُعمّم الاكتشاف على صفحات الدخول أو أي صفحة خارج المشغّل. يحافظ المسار على نص السؤال والرسم وبصمة السؤال وإقرار الاختيار قبل الإرسال. تُقرأ حاويات `display:contents` عبر الأبناء الظاهرين مع احترام الحجب على الأسلاف.

تُعاد قراءة قشرة الدرس التي لا تظهر سؤالًا أو أزرارًا بعد لمدة أقصاها 12 ثانية، وينتهي الانتظار فور ظهور السؤال أو زر المتابعة؛ التحميل الصريح يحتفظ بحد 30 ثانية. لا تعني القشرة وحدها وجود فيديو إلزامي. عند بقاء السؤال غير مقروء تظهر رسالة تصف فشل القراءة، ويمكن تصدير فحص يشمل أدوات إطار الدرس الذي حقنته الإضافة بالفعل، دون رمز الربط أو بكسلات الأسئلة.

يفحص العامل `/api/health` المحلي قبل START وRESUME، دون إرسال رمز الربط إلى هذا المسار. غياب الخدمة أو Ollama أو النموذج يمنع تغيير حالة الدرس أو فتح المادة، ويُظهر تعليمات `START-WINDOWS.cmd`. يُحجز فحص بدء واحد لكل تبويب، ويُلغيه STOP، وتُعاد مطابقة صفحة ألف قبل بدء التشغيل. لا يستطيع امتداد المتصفح تشغيل ملف Windows على الجهاز دون تشغيل المستخدم له.

## مطابقة الخيارات والأسس وانتظار الإطارات في 0.5.3

حدد سجل المستخدم خطأ الرياضيات بأنه `invalid_selection`: لم يقبل الخادم معرّفات الخيارات التي أعادها النموذج، وليس ذلك إثباتًا لعدم وجود جواب صحيح في السؤال. يستخدم طلب Ollama مخطط JSON Schema ديناميكيًا في `format` يضم معرّفات الخيارات الأصلية وحدود عددها، وينطبق ذلك على الطلبات النصية والبصرية وطلبي التحقق. يبقى الامتناع باختيار مصفوفة فارغة ممكنًا؛ يذهب الامتناع منخفض الثقة إلى المراجعة. لا تُحوّل تسمية الخيار أو ترتيبه أو حرف مفترض إلى معرّف، ولا يُرفع تقدير الثقة لتجاوز المراجعة. لم يُضف طلب إصلاح متكرر للنموذج.

يحافظ القارئ على بنية `sup/sub` العادية في النص والخيارات، حتى لا تُقرأ `2³` كـ`23`. تبقى علامات النقاط الأولية والوحدات والرتب والمراجع الصريحة متميزة، ويحافظ KaTeX وMathML على مصدرهما. يُنقل إخفاء العناصر من المستند المتصل قبل استنساخ نص السؤال؛ لا تدخل حدود مخفية عبر CSS في الحساب الدقيق، مع حفظ المصدر الدلالي داخل غلاف الرياضيات.

إذا ظهر إطار أو مؤشر تحميل بعد قشرة أولية بلا تحميل، تُرفع المهلة من 12 إلى 30 ثانية **من بداية الانتظار نفسها**. لا تُعاد المهلة مع كل تغيير، وتُحفظ آخر رسالة تشخيص محددة عند التوقف. زر Back وحده داخل شرح محمّل لا يمنع زر Next العادي الذي فعّلته المنصة، بينما السؤال غير المدعوم المعروف يبقى مانعًا للانتقال.

يتضمن تصدير الفحص نسخة محددة الحقول من آخر سؤال وخياراته وسياق درسه وسبب المراجعة، مع توضيح أنها مأخوذة من سجل التشغيل. لا يتضمن الإعدادات أو رمز الربط أو صور الأسئلة. يتطلب العميل الجديد بروتوكول الخادم 3، حتى لا تبدو الإضافة محدثة بينما بقي تنسيق النموذج القديم يعمل في نافذة START سابقة.

لم يصل بعد فحص المستند الفعلي لدرس «50. الاستعارة»؛ لا يثبت تحسين المهلة أو التنقل إصلاح محددات هذا الدرس. لا توجد مقارنة استدلال أو دقة حقيقية على جهاز RTX 4060 Ti سعة 8GB. بقي النموذجان الحاليان افتراضيًا؛ وجود مساحة تخزين كبيرة لا يثبت أن نموذجًا أكبر سيعمل أسرع في ذاكرة الكرت.

## نص المسألة المنفصل وأداء القارئ في 0.5.4

أظهرت لقطة المستخدم مسألة تشابه المثلثات بزاويتين أعلى خياراتها، بينما عرض مُعين عبارة `Select the correct answer.` وحدها. تؤكد شفرة Weaver العامة أن `aria-labelledby` لمجموعة الخيارات قد يشير إلى تعليمات الاختيار، و`aria-describedby` يشير إلى `question-statement-*`. كذلك يستخدم المشغّل المستقل `main#player-container` مع testId متغير، وقد يكون السؤال داخل `assessment-content-player`. لم تشمل حدود قراءة السياق السابقة كل هذه الأشكال.

يستعيد القارئ النص المرتبط مباشرة بالسؤال والسياق التعليمي السابق له داخل مشغّل معلوم ذي سؤال ظاهر واحد، مع الحفاظ على الصيغ الرياضية والإخفاء الأصلي. تبقى الخيارات ونتائج المحاولات والقوائم الجانبية منفصلة عن نص المسألة، ويغيّر تعديل النص الخارجي بصمة السؤال حتى لا تُطبّق إجابة قديمة. لا تُحفظ إجابة مسألة التشابه في القارئ أو الحل؛ تختبر المسألة تدفق النص والمعرّفات فقط. يُرفض نص تعليمات الاختيار وحده دون دليل مرئي قبل انتظار النموذج، مع سبب محدد لفقدان النص في الخادم أيضًا.

تُشارك قراءة الجذور والأنماط والظهور أثناء فحص متزامن واحد فقط، وتُمحى قبل النقر والانتظار. تتوقف `first()` عند أول عنصر ظاهر، ويستبدل فحص الأسلاف المقارنة الزوجية للبطاقات. لا تُحذف دروس لتقليل حجم الفحص. يفصل العامل بصمة تغيّر المحتوى عن تغيّر التحميل أو إتاحة الزر، ويمنع تكرار Next أثناء الانتقال، بما فيه الانتقال من نتيجة السؤال إلى قشرة شرح ما زالت تُحمّل. يتضمن التشخيص بنية جذر التطبيق وزمن الفحص دون نصوص الحساب أو قيم الحقول.

## شرائح الشرح المتطابقة في 0.5.5

أكد المستخدم حل درس كامل بإجابات صحيحة بعد 0.5.4، ثم توقف التشغيل في شرح «AA Similarity» برسالة منع تكرار Next، وأكد أن زر Next نفسه يسمح بالانتقال دون مشاهدة الفيديو. تعرض اللقطة شريطًا ملوّنًا دون عدّاد نصي. تؤكد المصادر العامة `SlideContainer.tsx` و`SlidesProgressBar.tsx` وجود معرّف الشريحة في غلاف `data-testid={slideId}` ومقاطع `bar-active/bar-inactive` داخل `slides-progress-bar`. يستخدم تخطيط K4 أسماء مكافئة، وقد يُخفي عدّاد `progress-bar-slide-count`.

تشمل بصمة التنقل الآن ترتيب حالات المقاطع ومعرّف الشريحة، حتى يُعرف الانتقال الحقيقي بين صفحات شرح لها النص نفسه وزر Next نفسه. لا تدخل أوقات الفيديو وأزرار تشغيله وترجماته الزمنية ضمن نص هذه البصمة، ولا تؤثر إعادة التحميل أو مصدر blob المؤقت على السماح بضغط جديد. يُستخدم Next الظاهر نفسه مباشرة؛ لا يُشغّل الفيديو أو يُنتظر انتهاؤه في هذا التعديل. يبقى منع تكرار Next في الشريحة التي لم تتغير. لا يتغير نص السؤال المرسل للنموذج أو طريقة الحل، والخادم متوافق مع 0.5.4.

## المحاولات والتفاعلات في 0.5.6

طلب المستخدم الإسراع بعد خسارة المحاولة الأولى، حتى لو ظل الموقع يعرض Try Again عدة مرات. يُفعَّل هذا المسار بعد إجابة أرسلها التشغيل نفسه ورفضتها المنصة، مع زر إعادة محاولة ظاهر. تُحفظ هوية السؤال وإطار مستنده؛ يُضغط الزر أولًا ويُنتظر فتح السؤال قبل أي كتابة أو اختيار جديد. لا يُستدعى النموذج أو التقاط الصورة مجددًا للسؤال نفسه. تُستخدم معرّفات الخيارات الحالية غير المجرّبة ثم يُعاد تدويرها، أو تُعاد قيمة الكتابة والمطابقة المعروفتان إذا ظلتا صالحتين. الحد 20 إعادة محاولة، ولا تتقدم قائمة الدروس إلا بعد دليل الإكمال المعتاد. لا يغيّر ذلك مراجعة المحاولة الأولى أو يسمح بتطبيق جواب على سؤال مختلف. تُعرض المحاولة السريعة دون ثقة نموذج مصطنعة أو ادعاء استعادة درجة.

تُقرأ الحقول المعطلة أو المقفلة أثناء عرض نتيجة الرفض للحفاظ على هوية السؤال؛ الإرسال يتطلب حقلًا حاليًا مفعّلًا وقابلًا للتعديل. يُستثنى combobox للبحث في React Select من منع القراءة فقط، لأن قائمة الاختيار تستخدم input للبحث وقد تجعله readonly عمدًا. يُربط منفذ القائمة بواسطة `aria-controls` أو `aria-owns` داخل المستند أو جذر الظل نفسه. عند غياب الربط يُطلب ظهور قائمة واحدة واضحة تابعة للتفاعل الحالي، ولا يُبحث عن أي نص خيار مطابق في جميع القوائم. يُنتظر فتح القائمة واختيار قيمة مطابقة كاملة، دون قبول جزء من النص.

يحافظ السحب على `buttons=1` حتى يُقرّ الموقع بدء السحب وموضع الفراغ، ويُعاد حساب إحداثيات الهدف بعد التمرير أو تغيّر التخطيط. لا تكفي مطابقة جزء من الكلمة لتأكيد الإسقاط، وتُراجع جميع الفراغات قبل الإرسال. الإيقاف أثناء الضغط يحرر السحب. تستخدم الكتابة محدد قيمة الحقل الأصلي مع أحداث الإدخال والتغيير، وتنتظر نافذة ثبات قصيرة للقيمة في الحقل الحالي بعد استبدال المكوّن، مع فحص صلاحية العدد وإعادة التحقق عند الضغط على الإرسال. لا يُرسل نجاح تطبيق وهمي إذا رفض الموقع هذه القيم.

الاختبارات لا تنفّذ تقييم ألف الحقيقي ولا تثبت دقة النموذج المحلي. لا يتجاوز البرنامج قفل الدرس أو متطلب مشاهدة إلزامي بدون زر تخطٍ متاح. تغيّر إصدار المنصة أو وجود إطار غير مسموح أو نوع سؤال غير مدعوم يظهر كتقرير تشخيص أو درس يحتاج مراجعة.
