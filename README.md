# مُعين — مساعد ألف المجاني على ويندوز

إضافة Chrome بواجهة عربية وخادم محلي. يستخدم الإصدار 0.5.17 **Ollama على جهازك**: نموذج `qwen3:8b` للنصوص و`qwen3-vl:8b` للأسئلة التي تجمع النص والصورة أو تعتمد على الرسم. لا يحتاج بطاقة بنكية أو اشتراكًا أو مفتاح API في الوضع الافتراضي. تُنزّل النماذج مرة واحدة، ثم تُعالج الأسئلة والصور محليًا. يحتاج موقع ألف نفسه إلى الإنترنت.

يحتاج التحديث من 0.4.2 إلى **تنزيل إضافي للنموذج البصري، عدة جيجابايت مرة واحدة**؛ يعرض Ollama الحجم والتقدم الفعليين. لا يُعاد تنزيل النموذج النصي الموجود. تبقى أوزان النماذج في مجلد Ollama المحدد لديك، مثل `D:\ollama\models`. ذاكرة RAM سعة 32GB تسمح باستضافة النموذج، لكن سرعة الاستدلال تعتمد على GPU وذاكرته والضغط عليه؛ قد يُحمّل Ollama جزءًا على CPU عند الحاجة. لم تُقَس دقة أو سرعة نموذج حقيقي في بيئة التطوير.

**حالة الربط:** يدعم القارئ واجهتَي Pathways والمهام المسندة Core Coursework، ومنها صفحة المادة ذات تبويبات «صفحتي / المهام المسندة / جميع الدروس». عند فتح «صفحتي» ينتقل إلى المهام المسندة، ويختار عرض الكل ليشمل المتأخر. يبدأ بأول درس متاح قبل تحميل بقية الصفحات، ويضيف بقية المهام قبل إنهاء الجلسة. يستخدم أزرار الشرح والتدريب المتاحة ويعود للقائمة لفتح التالي. بُني الربط من ملفات ألف العامة ويُختبر بمتصفح محلي؛ لم تُختبر الدورة الكاملة داخل حساب طالب، ولا تُضمن صحة كل الإجابات. مُعين أداة مستقلة وليست منتجًا رسميًا من ألف.

## التشغيل على ويندوز خطوة بخطوة

### 1. ثبّت البرنامجين المجانيين

- [Node.js](https://nodejs.org/en/download): اختر إصدار LTS لويندوز؛ يلزم 22.9 أو أحدث لأوامر npm.
- [Ollama لويندوز](https://ollama.com/download/windows): ثبّته بالطريقة المعتادة وافتحه.

أغلق نوافذ الأوامر القديمة وافتحها مجددًا بعد التثبيت حتى تتعرف على البرامج.

### 2. افتح مشروع مُعين

نزّل `alef-assistant-project.zip`، واضغط عليه بزر الفأرة الأيمن واختر **استخراج الكل**. ادخل المجلد المستخرج `alef-assistant`؛ لا تشغّل الملفات من داخل ZIP.

### 3. انقر START-WINDOWS.cmd مرتين

هذا هو ملف تشغيل ويندوز. سيفحص البرامج، ويشغّل Ollama عند الحاجة، ويجهّز `qwen3:8b` و`qwen3-vl:8b`؛ يحمّل النماذج الغائبة فقط. أول تشغيل قد يستغرق وقتًا حسب سرعة الإنترنت. يتحقق من أن النموذج البصري يعلن دعم الصور فعلًا قبل إعلان جاهزية الخدمة.

بعدها يشغّل مُعين، ويفتح صفحة التعليمات المحلية، وينسخ **رمز الربط المحلي** إلى الحافظة. اترك نافذة التشغيل مفتوحة أثناء الاستخدام. الرمز مولّد على جهازك، مجاني، وليس مفتاح خدمة ذكاء اصطناعي.

لا تحتاج إلى ملف `.env` أو إلى `npm install` لتشغيل النسخة المحلية؛ الخادم لا يعتمد على حزم خارجية. إذا لم يعمل نسخ الرمز تلقائيًا، افتح طرفية في المجلد واكتب `npm run token` وانسخ الرمز الذي يظهر.

### 4. أضف مُعين إلى Chrome

1. افتح `chrome://extensions` في شريط العنوان.
2. فعّل **وضع المطوّر** أعلى الصفحة.
3. اضغط **تحميل إضافة غير مضغوطة**.
4. اختر مجلد **extension** داخل المشروع المستخرج.
5. من زر الإضافات بجانب شريط العنوان، ثبّت **مُعين** ليظهر زرها.

### 5. اربط الصفحة وابدأ

1. افتح **https://moe.alefed.com/** وسجّل الدخول بنفسك، ثم افتح قائمة المواد.
2. اضغط زر إضافة **مُعين**.
3. افتح **إعدادات الربط** والصق الرمز المنسوخ تلقائيًا باستخدام `Ctrl + V`.
   يُحفظ الرمز فور اللصق على هذا الجهاز ويبقى بعد إغلاق صفحة الإضافة والمتصفح. تعرض الخانة تأكيد الحفظ؛ مسحها يحذف الرمز المحفوظ. بقية الإعدادات تستخدم زر الحفظ.
4. اضغط **فحص الاتصال**. سيبيّن إن كان Ollama يعمل والنموذج موجودًا. احفظ الإعدادات.
5. افتح الصفحة الرئيسية للمواد في ألف، ثم اضغط **افحص موادي** واسمح بقراءة هذا الموقع.
6. اختر المادة ثم **ابدأ الحل**. تظهر قائمة الدروس وحالة كل درس، ويتابع البرنامج الدروس والمستويات المتاحة بالتتابع. إذا كنت داخل درس معروف أصلًا، يمكن متابعة الدرس الحالي فقط.

تستخدم منصة ألف إطارات لبعض محتوى الدروس، ويحدد إعدادها العام نطاق محتوى مثل `content.alefed.com`. يطلب زر الفحص إذن Chrome للموقع ونطاق المحتوى المعروف. إذا احتاج إطار الدرس نطاقًا إضافيًا من ألف، يظهر زر **السماح بمحتوى الدرس**؛ السماح يستأنف الدرس نفسه مع الاحتفاظ بقائمة الدروس. لا يطلب مُعين صلاحية لجميع مواقع الإنترنت. تظهر عبارة **جارٍ الحل…** على زر البدء أثناء العمل، وتبقى تفاصيل الخطوة ظاهرة بجانبه.

يفحص زر البدء الخادم المحلي قبل فتح المادة. إذا تعذّر الوصول إلى `127.0.0.1:4318`، شغّل `START-WINDOWS.cmd` من مجلد المشروع على D واترك نافذته مفتوحة ثم اضغط **فحص الاتصال**. حفظ رمز الربط لا يشغّل الخادم. إذا كان Ollama أو النموذج غير جاهز، يظهر السبب قبل التنقل في الدروس.

خيار **الانتقال من الشرح إلى الأسئلة تلقائيًا** مفعّل افتراضيًا. يمرّ المشغّل على خطوات الدرس بالترتيب باستخدام Start وNext وI’ll try later عند إتاحته، دون القفز إلى قسم الأسئلة من القائمة الجانبية في NCLE. إذا لم يتوفر تخطٍّ لسؤال الشرح المدعوم يحاول حله وإرساله. لا يفتح الدروس المقفلة أو يزوّر إكمال الفيديو. إذا رفض الموقع الإجابة يستخدم Try again لإعادة تحقق محدودة، ويمنع تكرار الإجابة المرفوضة.

**عند التعذّر يبقى على الدرس الحالي** ويسجّل سبب التوقف؛ تظل بقية الدروس بانتظار الحل، ولا تُحسب المكتملة إلا بتأكيد من الموقع. لا ينتقل إلى الدرس التالي لمجرد وجود إجابة مقترحة. تعرض مساحة الإجابة اسم المادة والدرس وحالة الإجابة لتوضيح هل أُرسلت أم تحتاج مراجعة.

**دقة أعلى ومراجعة الإجابة** مفعّلة افتراضيًا في 0.5.0، وتُفعّل مرة واحدة عند ترقية إعدادات الإصدار السابق. تستخدم تفكير النموذج النصي ومراجعة مستقلة عند توفرها؛ قد تُرسل إجابة منخفضة الثقة قبل طلب المراجعة عند تفعيل المتابعة. بعض الحسابات الصريحة والعمليات على كثيرة حدود بمتغير واحد تُحسب بكسور وجبر دقيقين وتُطابق مع خيار وحيد، دون تخمين من النموذج. عند تعطيل الوضع يبقى اختيار السرعة محفوظًا، لكن تقل المراجعة. لا يضمن ارتفاع ثقة النموذج أو اتفاق حلين صحة الجواب.

**المتابعة عند انخفاض الثقة:** يفعّل 0.5.11 هذا الخيار عند الترقية لأول مرة حسب طلب المستخدم، ويحترم تعطيله وحفظه لاحقًا. يرسل أفضل إجابة كاملة متاحة حتى لو انخفض تقدير الثقة أو اختلفت المراجعة، ويعرض أنها غير مؤكدة دون رفع نسبة الثقة أو الادعاء بصحتها. قد تكون الإجابة خاطئة. عند تعطيل الخيار يعود التوقف للمراجعة. تبقى الإجابة الفارغة أو غير القابلة للتطبيق أو السؤال الذي تغيّر أو فقد صورته المطلوبة متوقفة؛ لا يختلق البرنامج معرّفات خيارات أو مواضع إدخال. يتطلب تحديث الخادم والإضافة معًا.

**الصور بالعربية والإنجليزية:** يرسل البرنامج نص السؤال وصوره الأصلية معًا، ويستخدم النموذج البصري بدل تمرير نص المسألة وحده إلى نموذج نصّي. يلتقط صور IMG والرسم على canvas وSVG وخلفيات الصور، ويربط صور الخيارات بمعرّفاتها. إذا منع المتصفح قراءة مصدر صورة ظاهرة، يستخدم 0.5.12 الإضافة لقراءة المصدر المحدد بإذن ألف، أو يقتطع الرسم كاملًا من التبويب المرتبط عندما يكون هو الظاهر. لا يرسل لقطة الصفحة الكاملة إلى النموذج. يقبل حاليًا حتى ثلاث صور بحد 1MB للصورة. إذا تعذّر تحميل الرسم أو قراءته أو تجاوز الحدود، يتوقف على السؤال ولا يرسل إجابة من سياق ناقص. لا تُحفظ بكسلات الصور في سجل جلسة الإضافة؛ تُرسل للخادم المحلي في طلب الحل فقط.

يمكن تعطيل **الإرسال التلقائي** لتجربة أول إجابة قبل إرسالها بنفسك. زر **إيقاف** يلغي طلب الحل الجاري ويمنع الخطوات التالية؛ لا يسترجع إجابات سبق إرسالها.

إذا لم تظهر مواد، افتح قائمة المواد في ألف وأعد الفحص. عند استمرار التعذّر، اضغط **تصدير فحص الصفحة**؛ ينتج ملف JSON محليًا بعناصر الواجهة بدون كلمات مرور أو قيم حقول الإدخال أو رمز الربط. راجع الملف قبل مشاركته. لا يضيف البرنامج مادة افتراضية عندما لا يعرف نوع الصفحة.

## تحديث نسخة سابقة دون تنزيل النموذج مجددًا

للترقية إلى **0.5.17 حدّث المشروع كاملًا وأعد تشغيل الخادم**، بما يشمل مجلدي `extension` و`server`. تصحيح حد خرج النموذج موجود في الخادم؛ لا يكفي استبدال مجلد الإضافة وحده لهذا الإصدار. أغلق نافذة التشغيل القديمة قبل تشغيل `START-WINDOWS.cmd` من الملفات المحدّثة. لا تحتاج تنزيل نماذج جديدة.

حدّث محتويات المشروع والإضافة معًا بالخطوات التالية. تحتاج الإصدارات الأقدم من 0.5.3 أيضًا تنسيق إجابة النموذج الجديد في الخادم. إذا كان النموذجان مثبتين فلا يحتاج هذا التحديث تنزيل أوزان أخرى.

1. أوقف الحل وأغلق نافذة `START-WINDOWS.cmd` القديمة.
2. فك ضغط النسخة الجديدة في مجلد مؤقت على D. انسخ محتويات مجلد المشروع الجديد إلى **مجلد المشروع الحالي نفسه** واختر استبدال الملفات. أبقِ مسار مجلد `extension` كما هو، ولا تحذف مجلدات Ollama أو رمز الربط.
3. افتح `chrome://extensions` واضغط **إعادة تحميل** لمُعين دون إزالتها. أغلق صفحات مُعين القديمة، وحدّث تبويب ألف باستخدام F5.
4. شغّل `START-WINDOWS.cmd` من المشروع المحدّث واترك نافذته مفتوحة. افتح مُعين وافحص الاتصال ثم المواد.

يظهر الإصدار 0.5.17 أسفل الواجهة. إذا بقي خادم قديم على المنفذ، يمنع فحص بروتوكول 3 البدء ويطلب تحديث المشروع وإعادة تشغيله. يبقى رمز الربط خارج مجلد المشروع في ملف المستخدم، ويُحفظ أيضًا في الإضافة عند الاحتفاظ بمسارها ومعرّفها. لا تُكتب بيانات الخادم أو إعداداتك فوق ملف `.env` الموجود.

يعالج 0.5.17 توقف «انتهى حد خرج النموذج قبل اكتمال الإجابة». تُستبعد أيقونات فراغات السحب من الصور حتى يُحل السؤال النصي بالنموذج النصي. إذا أبلغ Ollama صراحةً عن بتر التوليد، يعيد الخادم الطلب مرة واحدة بإجابة مختصرة وسعة خرج مناسبة دون التفكير المطوّل، ثم يبقي المراجعة المستقلة من السؤال الأصلي. تظل هذه الصيغة المختصرة لبقية طلبات السؤال نفسه حتى لا يتكرر استنفاد الخرج بالتفكير. لا تُستخدم أجزاء الجواب المبتور ولا تتغير الثقة، وإذا تكرر البتر لا تُطبّق إجابة. يلزم تحديث الخادم والإضافة معًا وإعادة تشغيل نافذة التشغيل القديمة.

يعالج 0.5.16 التوقف بعد قبول جواب الكتابة وظهور علامة الصح وزر Next. تُستبعد صور التصحيح التي يضيفها الحقل من أدلة السؤال حتى تبقى هويته ثابتة، ويُقرأ قبول الحقل المقفول من حالته الفعلية. يتابع مُعين بزر Next بعد القبول بدل طلب حل آخر للسؤال نفسه، ويمر إلى السؤال الجديد لحله. يشمل التصحيح علامات الخطأ للحفاظ على هوية Try Again، مع بقاء الصور الأصلية الصغيرة مطلوبة للحل. لا تتغير النماذج أو الخادم المحلي.

يعالج 0.5.15 الحاجة إلى اختيار تبويب ألف يدويًا لقراءة الرسم. لا تحتاج فصل نافذة مُعين عن نافذة ألف: يبدأ بالقراءة من المصدر، وإذا تعذرت يختار التبويب المرتبط مؤقتًا ويلتقط مساحة الرسم، ثم يعيد التبويب السابق ما دام المستخدم لم يغيّره. لا يغيّر تركيز نافذة Chrome أو حجمها، ولا يضيف صلاحيات أو نماذج. اترك نافذة ألف مفتوحة غير مصغرة أثناء الحاجة إلى الالتقاط.

يحسّن 0.5.14 جواب حقل الكتابة بعد القوائم أو الاختيارات: يطلب قيمة نصية غير فارغة في خانة الجواب نفسها، ويقيد قائمة معرّفات الاختيار بالقيمة الفارغة الدقيقة. إذا أعاد النموذج صيغة غير صالحة لسؤال كتابي، يحاول تصحيحها مرة واحدة باستخدام السؤال والصور الأصلية ضمن مهلة الطلب نفسها، ثم يبقي التحقق المستقل والإعداد المحفوظ للثقة كما هما. لا يزيد الطلبات عندما يكون الجواب صالحًا. إذا فشل التصحيح، يوضح أن المشكلة في الجواب النصي بدل عرض «خيارات الإجابة لا تطابق السؤال». يتطلب الإصلاح تحديث ملفات الخادم والإضافة معًا وإعادة التشغيل، دون تنزيل نموذج جديد.

يصحح 0.5.13 رسالة «طلب قراءة الرسم غير صالح» عند تغيّر مسار ألف دون إعادة تحميل الصفحة. يتحقق من رابط الإطار الحالي ومعرّف مستنده بدل اشتراط تطابقه مع عنوان بداية سياق الإضافة الذي قد تحتفظ به Chrome. يشمل الإصلاح قراءة الرسم ومحرر المعادلات، ولا يحتاج نموذجًا جديدًا أو إعادة إدخال رمز الربط.

يعالج 0.5.12 صور الأسئلة الظاهرة التي لا تسمح بقياس بكسلاتها من داخل الصفحة. بعد التحديث اضغط **افحص موادي** ووافق على سماح Chrome لصور ألف من `file-delivery.alefed.com`؛ يتيح ذلك قراءة المصدر أثناء بقاء ألف في الخلفية. إذا تعذر المصدر، تُلتقط مساحة الرسم الظاهر فقط. في 0.5.15 يختار مُعين تبويب ألف مؤقتًا داخل نافذته عند الحاجة، ثم يعيد التبويب السابق إذا لم تغيّره أثناء الالتقاط. لا يرفع نافذة Chrome فوق البرامج الأخرى، ولا يستخدم صورة تبويب آخر أو يحتفظ بلقطة كاملة في السجل. يلزم بقاء نافذة ألف مفتوحة غير مصغرة عندما يعتمد الحل على الالتقاط. لا يحتاج التحديث نموذجًا جديدًا.

يضيف 0.5.10 دعم محرر المعادلات MathLive ذي الحقل الواحد، بما يشمل الكسور والتعابير الرياضية. يمرّر الصيغة الرياضية للنموذج ويكتبها من خلال المحرر نفسه، ثم يقرأ القيمة من جديد ويتحقق من ثباتها قبل الإرسال. لا تُكتب الإجابة في مربع لوحة المفاتيح الداخلي، ولا يدخل عرض الإجابة ضمن نص السؤال أو صورته. يحتاج تحديث الخادم والإضافة معًا؛ لا يتطلب نموذجًا جديدًا.

يصحح 0.5.9 اكتشاف عناصر Weaver التي تبدأ أسماؤها بـ `lib-` في نسخة ألف المنشورة. كان القارئ يبحث عن الأسماء دون هذه البداية، فلا يتعرف إلى بعض القوائم والسحب والكتابة رغم ظهورها، وقد ينتهي بمهلة تحميل 30 ثانية. يشمل التصحيح اكتشاف السؤال ونصه وحقوله وإقرار القيم، مع استمرار دعم الأسماء القديمة. إذا ظهرت قائمة جاهزة في الصفحة العليا فلا يستبدلها العامل بإطار فرعي ما زال يُحمّل. لا يغير التحديث النموذج أو إعدادات دقة المحاولة الأولى، ولا يحتاج تنزيل أوزان جديدة.

يعالج 0.5.4 حالة فقدان نص المسألة عندما يظهر أعلى حاوية الخيارات، وتصل للنموذج عبارة «Select the correct answer» وحدها. يربط القارئ نص المسألة والخيارات داخل مشغّل السؤال نفسه، بالعربية والإنجليزية، ويحفظ الرسم المرتبط بهما. إذا بقيت التعليمات وحدها دون مسألة أو صورة، يتوقف فورًا برسالة توضح النص المفقود بدل انتظار استدلال لسؤال ناقص. لم تتغير النماذج، ولا يلزم تنزيل أوزان جديدة لهذا الإصلاح.

يقل أيضًا تكرار قراءة عناصر قائمة المواد داخل الفحص نفسه، وتنتهي الذاكرة المؤقتة قبل النقر أو الانتظار حتى تُقرأ تغييرات الموقع الجديدة. لا يُكرر «التالي» لمجرد تغير حالة التحميل. إذا أصبحت صفحة ألف بيضاء، أوقف التشغيل وصدّر فحص الصفحة **قبل F5**؛ يتضمن التقرير حالة تحميل المستند وبنية جذر التطبيق وزمن الفحص. هذه التعديلات لا تثبت سبب البياض في الحساب الفعلي؛ أفاد المستخدم أن إعادة فتح تبويب ألف أزالت الحالة السابقة.

في 0.5.5 يُقرأ شريط تقدّم شرائح الشرح حتى عندما يغيب العداد النصي. يسمح هذا بضغط Next في الشريحة التالية إذا كانت صفحة فيديو أخرى لها النص نفسه، مع استمرار منع تكرار النقر على الشريحة نفسها. لا يُنتظر تشغيل الفيديو عندما يكون Next متاحًا للانتقال. يخص التعديل التنقل في الشرح، وتبقى طريقة حل الأسئلة كما كانت في 0.5.4.

يحسّن 0.5.6 السحب والقائمة المنسدلة والكتابة. يبقى زر الماوس مضغوطًا حتى يؤكد الموقع بدء السحب، بما يشمل الدروس التي تحتاج قرابة ثانية، ثم يُراجع موضع الفراغ والكلمة كاملة قبل الإرسال. تُربط القائمة بحقل السؤال نفسه وتُنتظر خياراتها واختيارها، وتُراجع قيمة النص أو العدد داخل الحقل الحالي قبل الإرسال.

بعد رفض إجابة أُرسلت فعليًا وظهور **Try Again**، يضغط مُعين إعادة المحاولة أولًا ويستخدم محاولات محلية سريعة دون طلب حل جديد من النموذج للسؤال نفسه. يجرّب معرّفات الخيارات الحالية ويعيد تدويرها إذا استمر الزر، أو يعيد قيمة الكتابة والمطابقة المعروفتين عند بقائهما صالحَتين. يتوقف بعد 20 إعادة محاولة أو عند تغير السؤال أو تعذّر تأكيد التفاعل. لا تتغير طريقة حل المحاولة الأولى أو مراجعتها. تُوسم هذه المحاولات في الواجهة بوضوح؛ لا تضمن صحة الإجابة ولا استعادة درجة المحاولة الأولى.

يضيف 0.5.7 دعم سؤال يضم من قائمتين إلى 20 قائمة، مع ربط كل قائمة بفراغها وخياراتها، وإمكان اختيار القيمة نفسها في أكثر من فراغ. تُفتح القوائم بالتتابع، ويُرسل السؤال والرسم وخيارات كل قائمة معًا إلى النموذج. لا تُرسل الإجابة إلا بعد تثبيت القيم كلها. لا يُعامل شريط التقدّم المستمر كتحميل غير مكتمل عندما يظهر السؤال؛ تبقى الإطارات المطلوبة التي تُحمّل فعلًا مانعة للانتقال. يحتاج هذا النوع قدرة جديدة في الخادم المحلي، لذلك يطلب مُعين تحديث المشروع وإعادة تشغيل `START-WINDOWS.cmd` إذا بقي الخادم القديم.

يعالج 0.5.8 تعرّف القيمة المختارة في React Select: تتضمن قائمة Weaver عنصر عرض داخليًا داخل غلاف آخر، وكان القارئ يحسبهما اختيارين فيرفض الإقرار رغم وصول القيمة الصحيحة. تُقرأ القيمة الداخلية نفسها الآن، ويُستبعد إجراء Cancel الخاص بقائمة K4 من الخيارات القابلة للحل. تُختبر القوائم بمكتبة React Select الفعلية، والكتابة بحالة React المتحكم فيها، والسحب بمحرك DndKit الفعلي؛ حزم هذه المكتبات للتطوير والاختبار فقط، ولا تحتاج تثبيتها أو تنزيل نموذج جديد للتشغيل. يضم تقرير فحص الصفحة بنية الحقول والقوائم بعلاقات مجهولة القيم، وآخر مرحلة تفاعل، ومقارنة إصدار القارئ بإصدار الإضافة، دون كلمات المرور أو رموز الربط.

## التشغيل في المرات التالية

انقر **START-WINDOWS.cmd**. لن يُنزّل النموذج مجددًا إذا كان مثبتًا. يبقى رمز الربط محفوظًا في مساحة الإضافة المحلية المقصورة على سياقات الإضافة الموثوقة؛ لا يُرسل إلى صفحة ألف. تُنقل قيمة الجلسة القديمة تلقائيًا مرة واحدة. إزالة الإضافة أو مسح بياناتها يحذف الرمز المحفوظ.

## إذا كان بطيئًا

وضع **دقة أعلى ومراجعة الإجابة** يحتاج وقتًا إضافيًا للتفكير والتحقق. تعطيله يطلب حلًا واحدًا ويقلل المراجعة؛ يظل الرسم يُرسل إلى النموذج البصري إذا احتاجه السؤال. تُحسَب العمليات الصريحة المدعومة مباشرة في وضع الدقة. يُطلب من Ollama إبقاء النموذج في الذاكرة 15 دقيقة بين الأسئلة.

أغلق البرامج والألعاب الثقيلة وانتظر أول سؤال؛ تحميل النموذج إلى الذاكرة قد يزيد وقت الطلب الأول. لا تحدد ذاكرة RAM وحدها سرعة الحل؛ يعتمد ذلك على المعالج وكرت الشاشة والضغط عليهما. لم تُقَس سرعة استدلال حقيقي في بيئة التطوير، ولا توجد مدة مضمونة لكل سؤال.

للتحقق من استخدام كرت الشاشة، افتح PowerShell أثناء عمل النموذج وشغّل `ollama ps`. يعرض عمود `PROCESSOR` توزيع العمل بين GPU وCPU؛ ظهور القائمة فارغة يعني أن النموذج غير محمّل وقت الفحص. تشغيل لعبة وOllama معًا قد يقلل ذاكرة كرت الشاشة المتاحة ويزيد زمن الحل.

لتجربة نموذج أخف، افتح Command Prompt داخل مجلد المشروع:

```bat
set SOLVER_LOCAL_MODEL=qwen3:4b
START-WINDOWS.cmd
```

يتحقق المشغّل من وجود النموذج البديل ويحمّله عند الحاجة. لا يتطلب الخيار الأخف دفعًا، ولا يضمن تطابق الدقة مع النموذج الأكبر.

## أسئلة شائعة

- **هل أحتاج API key؟** لا في وضع Ollama الافتراضي. رمز الربط مجاني ويولّده البرنامج؛ ليس مفتاحًا مدفوعًا.
- **هل أحتاج حساب ChatGPT؟** لا.
- **هل يعمل دون إنترنت؟** الاستدلال المحلي يعمل بعد تثبيت Ollama وتنزيل النموذج. الدخول إلى ألف وتنزيله يحتاجان الإنترنت.
- **هل كل الإجابات صحيحة؟** لا يمكن ضمان ذلك. عند تفعيل المتابعة عند انخفاض الثقة يمكن إرسال إجابة غير مؤكدة؛ وعند تعطيلها يتوقف للمراجعة. قد يكون جواب النموذج خاطئًا رغم ارتفاع ثقته أو اتفاق المراجعة.
- **هل يعالج الصور والسحب والإفلات؟** يدعم النص والصور بالعربية والإنجليزية ضمن حدود القراءة الموضحة، والاختيار الواحد والمتعدد، وحقل نص واحد، وقائمة منسدلة واحدة أو عدة قوائم مستقلة في السؤال نفسه، والمطابقة النصية، ووضع الكلمات في فراغات عندما يوفر العنصر تفاعلًا واضحًا. يدعم أيضًا محرر MathLive واحدًا لإجابة رياضية. عدة حقول كتابة أو معادلات، ومحررات أخرى وبعض السحب المخصص قد تحتاج مراجعتك.
- **أين تُرسل أسئلتي؟** افتراضيًا إلى Ollama على جهازك فقط. لا يقرأ مُعين كلمة مرور ألف. إذا غيّرت إعداد الخادم إلى مزوّد خارجي اختياري، تُرسل الأسئلة إلى ذلك المزوّد.
- **هل أستطيع إغلاق نافذة التشغيل؟** إغلاقها يوقف مُعين. استخدم `Ctrl + C` للإيقاف المنظم.
- **ظهر خطأ أن المنفذ مستخدم؟** أغلق نافذة مُعين السابقة التي شغّلتها ثم جرّب مجددًا. المشغّل لا يقتل عمليات جهازك الأخرى.

## تشغيل يدوي على ويندوز أو أنظمة أخرى

بعد تثبيت Node.js وOllama، افتح طرفية في مجلد المشروع:

```sh
ollama pull qwen3:8b
ollama pull qwen3-vl:8b
npm start
```

شغّل تطبيق Ollama أولًا، أو `ollama serve` في نافذة ثانية إذا لم يكن يعمل. احصل على رمز الربط في نافذة أخرى باستخدام `npm run token`، واتبع خطوات إضافة Chrome أعلاه.

### إعدادات اختيارية

القيم الافتراضية كافية للتشغيل المجاني. للتخصيص انسخ `.env.example` إلى ملف محلي باسم `.env`:

| المتغير | الافتراضي والغرض |
| --- | --- |
| `SOLVER_PROVIDER` | `ollama`؛ مجاني ومحلي |
| `SOLVER_MODEL` | `qwen3:8b` عند التشغيل اليدوي |
| `SOLVER_VISION_MODEL` | `qwen3-vl:8b` للأسئلة التي تحتاج صورًا؛ يُفحص دعم الرؤية عبر Ollama |
| `SOLVER_BASE_URL` | `http://127.0.0.1:11434`؛ اتصال محلي فقط في وضع Ollama |
| `SOLVER_LOCAL_MODEL` | اختياري لمشغّل ويندوز: اختيار النموذج المحلي |
| `SOLVER_LOCAL_VISION_MODEL` | اختياري لمشغّل ويندوز: اختيار نموذج الصور المحلي |
| `SOLVER_LOCAL_BASE_URL` | اختياري لمشغّل ويندوز: عنوان Ollama محلي آخر |
| `SOLVER_TIMEOUT_MS` | المهلة الكلية للحل والتحقق؛ افتراضيًا 240000 ملّي ثانية |
| `SOLVER_PORT` | منفذ مُعين؛ افتراضيًا `4318` |
| `SOLVER_CONFIG_DIR` | اختياري: مجلد رمز الربط؛ افتراضيًا `.alef-assistant` في مجلد المستخدم |

يدعم الخادم خيارًا خارجيًا مستقلًا باستخدام `SOLVER_PROVIDER=openai`، وعنوان HTTPS ومفتاح `SOLVER_API_KEY`. لا تحتاج إليه أو إلى إدخال مفتاح للتشغيل المجاني. مشغّل ويندوز يختار Ollama حتى لو كان لديك ملف قديم لإعداد مزوّد خارجي، دون تعديل ذلك الملف.

## التطوير والاختبار

```sh
npm ci --ignore-scripts
npm run check
npm test
```

تستخدم اختبارات القوائم والسحب والكتابة أيضًا React وReact Select وDndKit الفعلية، وتُجمع ملفات JSX في الذاكرة بواسطة esbuild؛ لا تُضمّن حزمها في تشغيل الخادم. اختبارات المتصفح تستخدم Chromium الموجود في الجهاز، أو متصفح Playwright. إذا لم يوجد متصفح:

```sh
npx playwright install chromium
npm run test:browser
```

اختبارات خدمة Ollama تستخدم خادم HTTP محليًا يطبّق البروتوكول للاختبار، ولا تثبت دقة نموذج حقيقي. اختبارات تشغيل ويندوز تتحقق من ترتيب العمليات والتعامل مع الفشل؛ لا تثبت التشغيل الفعلي على ويندوز من بيئة Linux. التفاصيل في [docs/VALIDATION.md](docs/VALIDATION.md).

لتجهيز ملف الإضافة والمشروع الكامل يلزم Python 3:

```sh
npm run package
```

ينتج `dist/alef-assistant.zip` للإضافة وحدها و`dist/alef-assistant-project.zip` للمشروع الكامل. لا تُضمّن ملفات `.env` أو مفاتيح الخدمات أو رموز الربط أو أوزان النماذج في الأرشيف.
